# Java Playground ☕

A structured repository dedicated to practicing **Data Structures & Algorithms (DSA)** and core **Java** concepts.

---

## 📂 Repository Structure

### [11) Array (Part 1)](./11)Array(Part1))
Basics of arrays, searches, and elementary manipulations:
- **Creation & I/O**: `arrayCreation.java`, `arrayInput.java`, `arrayArgument.java`
- **Searching**:
  - `linearSearch.java` — $O(n)$
  - `binarySearch.java` — $O(\log n)$
- **Operations**:
  - `largestNumber.java` — Find largest/smallest element
  - `arrayReverse.java` — In-place array reversal
  - `arrayPairs.java` — Print all unique pairs
  - `arraySubarrays.java` — Print all subarrays

### [12) Array (Part 2)](./12)Array(Part2))
Advanced array problems and optimizations:
- **Max Subarray Sum**:
  - `maxSubarray.java` — Brute Force ($O(n^3)$)
  - `maxSubarrayPrefixSum.java` — Prefix Sum ($O(n^2)$)
  - `maxSubarrayKadanes.java` — Kadane's Algorithm ($O(n)$)
- **Classic Problems**:
  - `trappedRainWater.java` — Trapping Rain Water problem ($O(n)$ auxiliary array approach)

## 🚀 How to Run

Navigate into any topic folder and use the Java compiler:

```bash
# Compile
javac <FileName>.java

# Run
java <FileName>
```
